# イキモノ.コムへの転送ページ

公開URL: https://ikimono-links.github.io/ikimono/

転送先: https://xn--ecks3h9c.xn--tckwe/

JavaScriptのlocation.replaceで転送し、JavaScriptが無効の場合は3秒後のmeta refreshで転送します。自動転送が使えない環境のために「イキモノ.コムを開く」の手動リンクと転送先を表示します。URLのクエリーやフラグメントは引き継ぎません。

GitHub Pagesはmainブランチのルートから公開します。独自ドメインは設定しません。専用Organizationを使うことで、既存のmonomiki.github.ioの独自ドメイン設定から分離しています。既存の公式サイトのファイル、DNS、独自ドメイン設定は変更しません。

Blueskyでは、プロフィール → プロフィールを編集 → リンクを追加 で公開URLとタイトル「イキモノ.コム」を入力します。この公開作業ではBlueskyのプロフィールを保存・変更しません。
